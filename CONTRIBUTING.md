# Contributing

Thanks for helping improve Bases Conditional Format.

## Development

Plain JavaScript with no build step and no dependencies.

1. Clone into `<vault>/.obsidian/plugins/bases-conditional-format/` of a test vault.
2. Enable **Bases Conditional Format** in Settings → Community plugins.
3. Run tests before opening a pull request:

   ```bash
   node tests/run.js
   ```
