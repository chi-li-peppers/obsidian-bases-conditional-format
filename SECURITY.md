# Security policy

## How Bases Conditional Format handles your data

- Bases Conditional Format makes **zero network requests** and stores no credentials.
- It only applies CSS classes and CSS variables locally inside your Obsidian UI and never modifies your Markdown files.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/chi-li-peppers/obsidian-bases-conditional-format/security/advisories/new) instead of opening a public issue.
